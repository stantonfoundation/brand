# Handoff

`design_handoff_scpf_website/` holds the original design handoff exactly as it was delivered in `Stanton Foundation Style Guide.zip`: a static homepage design (`index.html`), its stylesheet (`css/styles.css`), its README and the logo PNG. Open `index.html` in a browser to see the design.

The website was built from these same files in August 2026, so the design predates the zip's file dates (2026-10-17).

Do not edit these files. The current system lives in `tokens/`, `css/` and `guidelines/`. `CHANGELOG.md` lists every difference from this handoff.

The homepage is a design mockup. Its copy, dollar figures, quote, events and EIN (`59-0000000`) are the designer's placeholders, not facts about the Foundation. The Foundation's EIN is 42-3219928.
