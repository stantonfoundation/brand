# Handoff

`design_handoff_scpf_website/` is the unchanged content of `Stanton Foundation Style Guide.zip`: the original static homepage design (`index.html`), its stylesheet (`css/styles.css`), its README, and the logo PNG. Open `index.html` in a browser to see the design as delivered.

The files in the zip are dated 2026-10-17, but the same files were ported into the website on 2026-08-16 (`design-export/` in the website repo is byte-identical). The design itself dates from August 2026 or earlier; the zip was packaged later.

Do not edit these files. The current system lives in `tokens/`, `css/` and `guidelines/`; `CHANGELOG.md` lists every difference from this handoff.

The homepage copy, dollar figures, the quote attributed to "Dr. Anita Reyes", the events and the EIN `59-0000000` are placeholders from the designer, not real Foundation facts. The real EIN is 42-3219928.
